# Executive communication

This entry point preserves the `executive-communication` skill name for existing
installations of this repository.

Before performing the requested task, read
[the complete executive strategic positioning instructions](executive-strategic-positioning/SKILL.md).
Apply that file's working rules, task selection, frameworks, and delivery checks.
Its frontmatter identifies the standalone package; keep the current invocation name
when using this entry point.

The instructions cover executive presentations, meeting questions, linking work to
leadership priorities, converting data into insights, and positioning assessments.
Use the mode that matches the user's request and write in the requested output language.
